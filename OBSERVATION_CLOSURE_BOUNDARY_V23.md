# V23 — Observation Closure Boundary

## Question
After V22 removes the supplied cell/slot/selector substrate, is there any further information-gaining representational move available **without adding new primitive contact with runtime state**?

## Frozen setup
- V22's accepted G1+G2+G3 projection-site semantics and discovery corpora are unchanged.
- Discovery uses dependency-complete Std and Cedar prefixes through row 400000.
- The verifier label is unchanged: `safe := ptr::eq(struct_ty, force_all(depth, struct_ty))`.
- The *accessible observation signature before V22 substrate expansion* is frozen to the observations already available at that boundary: root discriminant, context depth, and the generic facts `spine_empty`, `closed`, `canonical`.
- No payload decomposition, nested-head source, cell sequence, slot selector, or V22 `sigma0` source is available to the closure learner.

## Universal closure test
Let `o(x)` be the complete frozen accessible observation signature. Any deterministic generated Boolean observation/predicate/program using no new state access factors through `o`: `h(x)=f(o(x))` for some deterministic `f`.

Therefore if two real kernel events `x,y` satisfy `o(x)=o(y)` but have different verifier labels, **no deterministic closure of the current observation language can separate them**. This is independent of grammar depth, search strategy, or compute budget.

The experiment will:
1. collect the same real projection-site events from Std+Cedar;
2. partition them by the full frozen accessible signature `o`;
3. find and count mixed verifier-label classes;
4. compute the exact maximum safe coverage possible at zero unsafe for *any* Boolean function of `o` (select precisely the pure-safe signature classes);
5. verify this universal bound matches the pre-substrate frontier;
6. then expose only the already-validated V22 `sigma0` witness source and show the obstruction is broken, reaching the full safe frontier;
7. compile a Lean theorem proving the factorization/no-separator statement abstractly.

## Deciding classification
`OBSERVATION_CLOSURE_BOUNDARY_V23=GENUINE_INFORMATION_BOUNDARY` iff:
- both safe and unsafe real events occur;
- at least one frozen-observation equivalence class contains both labels;
- the exact universal zero-unsafe safe-coverage bound under the frozen signature is strictly below all safe events;
- adding the previously validated V22 `sigma0` source strictly refines at least one mixed class and recovers the full safe frontier under the frozen low-level transform/predicate rule;
- the Lean closure theorem compiles.

If there is no mixed class, classification is `NO_INFORMATION_BOUNDARY` and another search move remains possible. If `sigma0` does not break the collision, classification is `V22_WITNESS_INCONSISTENT`. Operational failures are not scientific outcomes.

## Interpretation boundary
A positive V23 does **not** say no richer externally grounded sensor or runtime primitive can ever be invented. It establishes the exact opposite constraint: new consequential distinctions cannot be generated by pure composition when the current primitive observations already identify the states. To move further, the system must gain new primitive contact with state (a new measurement/destructor/sensor supplied by or licensed through the environment/runtime). That is the principled stopping boundary of representation genesis from consequence alone.
