# V26 — Endogenous closure genesis

## Question

Can a real Lean-kernel residual force a change not merely in a supplied observation/action choice, but in the **generator of the future measurement closure itself**?

V25 selected one measurement action from a finite hand-supplied action menu. V26 removes that menu.

The initial learner receives only:

- opaque local root,
- generic Boolean/context facts,
- verifier-labelled safe/unsafe outcomes.

It does **not** receive a named action list, named traversal primitive, named semantic source, slot family, cell sequence, or semantic head labels.

A frozen anonymous two-operation interaction algebra generates bounded candidate programs. Candidate programs are quotiented by downstream behavioural effect. The learner must synthesize a minimal generator program whose installation strictly enlarges the safe reachable closure, then synthesize a downstream guard from the newly generated observation.

## Frozen deciding criteria

Positive requires all of the following:

1. Initial generator closure is insufficient.
2. A generated interaction program strictly increases the exact safe frontier.
3. There is exactly one best behavioural generator class at minimum generated cost.
4. The downstream guard is reachable only after installing that generator.
5. Exact generator-class ablation collapses the frontier below the installed result.
6. No supplied action menu or semantic measurement source is exposed to the learner.
7. Generated guard is byte-identical to the frozen baseline on Std and Cedar discovery prefixes.
8. Broadening the generated predicate fails on at least one discovery corpus.
9. Generated guard remains byte-identical on untouched rows 400001..600000 of Std and Cedar.

## Claim boundary

A positive result is **bounded endogenous closure genesis in a real Lean checker**: a verifier-labelled residual causes synthesis and installation of a generator whose closure contains a downstream safe routing capability absent from the initial generator closure.

It is not unrestricted experiment invention. The anonymous `u/e` interaction algebra and bounded program depth remain supplied as the meta-language. The scientific advance over V25 is that the action menu itself is no longer supplied; individual measurement actions are generated from the lower-level algebra and selected only by consequence.
