## Decision rule

A local speedup is not a retained capability by itself.

A release candidate must preserve protected semantic consequences and must be evaluated in the *current portfolio context*. The Rigid V2 result is the canonical example: its standalone value collapsed on the newer present, while its value in composition with app_hc became material.

Therefore the optimization unit is the compatible implementation portfolio, not the isolated patch.

## Public evidence discipline

For Arena-facing work:

1. publish exact commit hashes;
2. distinguish local wall time, Callgrind, and official Arena instruction results;
3. report semantic mismatches even when performance improves;
4. preserve informative rejected experiments;
5. credit upstream implementation lineage;
6. do not claim an Arena rank until the Arena has measured the pinned revision.
