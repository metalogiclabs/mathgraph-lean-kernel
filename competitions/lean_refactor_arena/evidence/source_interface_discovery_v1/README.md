# Source interface discovery v1

This experiment applies the recovered MSI pattern as a bounded source-acquisition
step: generate a finite representation library, measure with the native verifier,
select from source outcomes, and evaluate a fixed operator on a second family.

The source is the submitted V16 portfolio. `source_interface_discovery.py` takes
proof text alone: it acquires existing congrArg observers, equality names and
terminal rw normalization lists, then emits inferred-observer and fused-normalizer
candidates. No theorem-specific site or interface specification is supplied.
Each candidate carries exact parent/proof SHA256 hashes and source provenance.
The mathematical equality witnesses and transformation grammar are not invented.

`acquisition.json` binds the immutable bank and experiment commit. Controls are
exact V16 proof fields. The four generated candidates have no exact match among
proof fields in the 16 previous experiment JSONL files. Discovery is conservative
lexical extraction, not a complete Lean parser.

Native execution: workflow `lean-refactor-arena-source-discovery.yml`, pinned
public harness 7f3a401470d04f70013d293db4253b088ec8a0ae. Both selected Physlib
theorems require v4.32.0 only. Every baseline and candidate uses the same public
measurement path. Selection requires compilation, unchanged statement, eligibility,
actual complete required-version coverage and strict joint objective improvement.
The selector's exact v4.32.0 gate is scoped to this experiment; other families
require their own full benchmark version matrix before admission.

The pre-outcome `transfer` policy fits only on EM scores, then applies that exact
operator to Wick in frozen candidate order. It never chooses an operator using
Wick costs. No source gain or no applicable target candidate are explicit outcomes.
The V16 baseline physically deletes the newly acquired representation. Both tasks
were previously inspected warmups; this is not a blind heldout test.

Native results are not equivalent to a leaderboard submission. The generator,
selector and experiment never modify the retained portfolio. Any measured winner
requires separate exact packet reconciliation and official evaluation. Final
competition generation-budget eligibility remains unknown.
