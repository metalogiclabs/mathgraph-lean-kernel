# V14 Feature-Language Genesis — preregistration

## Question
Can a verifier residual show that the current observation language is insufficient, license the smallest new anonymous probe from a frozen generic probe generator, and thereby make a previously unreachable maximally safe applicability region expressible and prospectively valid?

## Frozen starting point
V13 learned a valid applicability predicate from 15 anonymous primitive observations. V14 removes all discriminant-derived observations from the initial learner. The initial condition language contains only three generic facts already available on a local rigid value:

- `b0`: spine is empty;
- `b1`: value is closed;
- `b2`: value is canonical.

The verifier label remains exactly the V13 semantic evidence: whether forcing the pre-force projection structure type preserves the identical value pointer. This label is evidence only and is never available to the deployed guard.

For every condition language, the frozen objective is lexicographic: maximize coverage of verifier-safe events subject to zero verifier-unsafe coverage, then minimize predicate description length, then quotient syntactic ties by their behavioural truth vector on discovery events. The initial language is scientifically insufficient only if its best zero-unsafe rule covers strictly fewer safe events than the best rule reachable after one generated probe. Thus a partial safe guard in the initial basis does not erase a genuine uncovered-safe residual.

## Frozen probe generator
Only after measuring the initial frontier may the system generate one new anonymous probe from this mechanically defined family:

`p_k(x) = bit_k(hash(discriminant(head(x))))`, for `k = 0..11`.

The generator contains no `RigidHead` semantic variant names and no `Inductive`/`Recursor` menu. Each candidate has equal generation cost 1. For each generated probe, the learner adjoins that one bit to the three initial facts and recomputes the frozen objective. The selected generated probe must produce the uniquely best behavioural frontier: greatest zero-unsafe safe coverage, then least predicate cost. Ties between inequivalent probe/predicate behavioural classes yield `UNDERIDENTIFIED`.

This is bounded feature-language genesis, not unrestricted invention: the meta-grammar `bit_k(hash(discriminant(...)))` is supplied, while the useful probe and applicability predicate are selected by residual evidence.

## Discovery / transfer split
Discovery uses dependency-complete Std and Cedar prefixes through row 400000. Prospective transfer uses rows 400001..600000 through the same dependency-complete 600000-row prefixes.

## Deciding gates
1. Probe/build succeeds on Std and Cedar and both safe and unsafe events occur.
2. The initial three-feature frontier is measured before generated candidates are scored.
3. A strict representational residual exists: the selected one-probe language covers more verifier-safe events at zero unsafe coverage than the initial language. Otherwise classify `NO_GENESIS_NEEDED`.
4. The frozen generator yields one minimum behavioural probe/predicate class at the best enlarged frontier; otherwise classify `UNDERIDENTIFIED`.
5. Exact probe ablation: removing the generated probe restores the strictly smaller initial frontier.
6. Exact predicate broadening ablation: the nearest strictly broader generated predicate must fail or disagree with G3 on at least one discovery corpus.
7. The generated learned guard is byte-identical to G3 on Std and Cedar at the 400k discovery boundary.
8. The same frozen generated probe and predicate are byte-identical to G3 on Std and Cedar at the 600k boundary.

## Classification
- `FEATURE_LANGUAGE_GENESIS_V14=BOUNDED_POSITIVE` iff gates 1–8 pass with a strict initial-to-generated frontier expansion.
- `FEATURE_LANGUAGE_GENESIS_V14=NO_GENESIS_NEEDED` if no generated probe strictly expands the initial zero-unsafe safe frontier.
- `FEATURE_LANGUAGE_GENESIS_V14=UNDERIDENTIFIED` if residual evidence does not uniquely license a generated probe/predicate behavioural class.
- `FEATURE_LANGUAGE_GENESIS_V14=FALSIFIED` if a uniquely licensed generated probe/predicate fails prospective semantic transfer.

## Boundary
V14 tests residual-driven growth of a bounded anonymous observation language. It does not establish unrestricted concept formation, automatic invention of the probe meta-grammar, or general representation-language discovery.
