# V14 Feature-Language Genesis — preregistration

## Question
Can a verifier residual show that the current observation language is insufficient, license the smallest new anonymous probe from a frozen generic probe generator, and thereby make a previously unexpressible safe applicability condition expressible and prospectively valid?

## Frozen starting point
V13 learned a valid applicability predicate from 15 anonymous primitive observations. V14 removes those discriminant-derived observations from the initial learner. The initial condition language contains only three generic facts already available on a local rigid value:

- `b0`: spine is empty;
- `b1`: value is closed;
- `b2`: value is canonical.

The verifier label remains exactly the V13 semantic evidence: whether forcing the pre-force projection structure type preserves the identical value pointer. This label is evidence only and is never available to the deployed guard.

## Frozen probe generator
If and only if the initial basis cannot express a licensed applicability predicate, the system may generate one new anonymous probe from this mechanically defined family:

`p_k(x) = bit_k(hash(discriminant(head(x))))`, for `k = 0..11`.

The generator contains no `RigidHead` semantic variant names and no `Inductive`/`Recursor` menu. Each candidate has equal description cost 1. The residual scores candidates only by verifier-labelled behavioural separation. The chosen generated probe is the unique candidate (or unique behavioural class) that, when adjoined to the initial basis, permits the maximum safe coverage with zero unsafe coverage at minimum predicate cost. Ties between inequivalent generated probes yield `UNDERIDENTIFIED`.

This is bounded feature-language genesis, not unrestricted invention: the meta-grammar `bit_k(hash(discriminant(...)))` is supplied, while the useful probe and applicability predicate are selected by residual evidence.

## Discovery / transfer split
Discovery uses dependency-complete Std and Cedar prefixes through row 400000. Prospective transfer uses rows 400001..600000 through the same dependency-complete 600000-row prefixes.

## Deciding gates
1. Probe/build succeeds on Std and Cedar and both safe and unsafe events occur.
2. Initial-basis test is performed before candidate generation. If the initial three-feature language already has a licensed rule, classify `NO_GENESIS_NEEDED` and stop the genesis claim.
3. If initial basis is insufficient, the frozen generator must produce a unique minimum behavioural probe class; otherwise classify `UNDERIDENTIFIED`.
4. The generated probe plus initial basis must yield a unique minimum licensed applicability predicate.
5. Exact probe ablation: removing the newly generated probe must restore the initial inability to license that rule.
6. Exact predicate broadening ablation: the nearest strictly broader generated predicate must fail or disagree with G3 on at least one discovery corpus.
7. Learned guard is byte-identical to G3 on Std and Cedar at the 400k discovery boundary.
8. The same frozen generated probe and predicate are byte-identical to G3 on Std and Cedar at the 600k boundary.

## Classification
- `FEATURE_LANGUAGE_GENESIS_V14=BOUNDED_POSITIVE` iff gates 1–8 pass after an initial-language failure.
- `FEATURE_LANGUAGE_GENESIS_V14=NO_GENESIS_NEEDED` if the initial three-feature language already suffices.
- `FEATURE_LANGUAGE_GENESIS_V14=UNDERIDENTIFIED` if residual evidence does not uniquely license a generated probe/predicate.
- `FEATURE_LANGUAGE_GENESIS_V14=FALSIFIED` if a uniquely licensed generated probe/predicate fails prospective semantic transfer.

## Boundary
V14 tests residual-driven growth of a bounded anonymous observation language. It does not establish unrestricted concept formation, automatic invention of the probe meta-grammar, or general representation-language discovery.
