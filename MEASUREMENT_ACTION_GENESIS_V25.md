# V25 — Measurement-Action Genesis

## Question
Can a verifier residual force synthesis of a useful diagnostic measurement action, rather than choosing or composing a supplied passive traversal/measurement API?

## Frozen setup
- Accepted G1 + G2 + G3 (`final_field_pi`) prefix is frozen.
- Discovery corpora are dependency-complete Std and Cedar prefixes through row 400000.
- Prospective evaluation extends through row 600000; rows 400001..600000 are untouched during selection.
- Verifier label remains `safe := ptr::eq(struct_ty, force_all(depth, struct_ty))` at the projection site.
- Initial language exposes only root discriminant, generic facts (`spine_empty`, `closed`, `canonical`), and context depth.
- No `touch`, `sense`, `enter`, `advance`, `emit_disc`, payload decomposition, cell sequence, slot family, nested-head observation, or semantic field name is available to the learner.

## Residual-driven measurement-action genesis
If the initial zero-unsafe frontier is incomplete, a bounded anonymous intervention generator becomes available:
- `act(root, i)` creates an opaque diagnostic intervention/view using anonymous action index `i`;
- `delta(root, act(root,i), j)` emits an anonymous scalar consequence/readout using anonymous readout index `j`.

The learner receives no semantics for either index. It must select a complete action+readout program from equal-budget candidates containing distractors. Candidate names contain no Rust variants, field names, traversal semantics, payload positions, or predeclared measurement operation.

For each generated scalar, the frozen low-level observation grammar is `shr`, `and`, `mod`, `neq0` plus integer constants. Predicate language is conjunctions over generic facts and generated Boolean `g`.

Selection objective, lexicographically:
1. maximize safe coverage at zero unsafe coverage;
2. minimize action-program + observation-program + predicate description length;
3. quotient syntactic ties by generated truth vector / behavioural predicate signature.

## Deciding gates
1. Both safe and unsafe discovery events occur.
2. Initial measurement language frontier is strictly below the best generated-action frontier.
3. Exactly one best behavioural measurement-action class exists.
4. Exact action ablation: remove every candidate in the selected behavioural action class and rerun synthesis; best zero-unsafe frontier strictly falls.
5. No passive traversal micro-machine, named traversal primitive, combined decomposition operator, cell sequence, slot family, semantic Rust variant name, or semantic field name is exposed to the learner.
6. Generated guarded checker is byte-identical to frozen G3 on Std and Cedar through row 400000.
7. Broadening the learned predicate to `TRUE` fails or disagrees on at least one discovery corpus.
8. The same frozen action/source/program/predicate is byte-identical to G3 on Std and Cedar through row 600000.

## Classification
`MEASUREMENT_ACTION_GENESIS_V25=BOUNDED_POSITIVE` iff gates 1–8 pass. Otherwise `NO_GENESIS_NEEDED`, `UNDERIDENTIFIED`, or `FALSIFIED` is retained as the scientific result.

## Boundary
A positive result establishes bounded verifier-governed selection/synthesis of a diagnostic action from a supplied finite anonymous intervention generator. It does not establish unrestricted experiment invention, causal discovery, arbitrary state mutation, raw memory-layout discovery, or autonomous invention of the intervention meta-generator. The remaining crutch would be the finite `act/delta` generator and its anonymous action/readout spaces.
