## Reproduce

All helpers accept data/tool locations as CLI paths. `tools.json` preserves observed execution paths; replace it with local paths when replaying elsewhere. `candidate-binaries.json` gives observed native pins; preserved449/C++ pins are in recipes. C++ binaries must execute from their release locations with matching shared libraries. The historical helper does not silently allow a different build.

Regenerate pinned original/expanded workload exports using source5dfe setup/build scripts, or obtain the public full qualification artifact. `decoder.py` is an independent standalone decoder copied byte-identically from the earlier independently replayed recipe package. It consumes the included recipes and tiny deltas, not the incremental engine:

```sh
python decoder.py --original-baseline /path/original/baseline/export.ndjson \
  --expanded-baseline /path/expanded/baseline/export.ndjson --out /path/inputs
ln -s /path/original/baseline/export.ndjson /path/inputs/original-baseline.ndjson
ln -s /path/expanded/baseline/export.ndjson /path/inputs/expanded-baseline.ndjson
python replay_full.py --repo /path/repo --inputs /path/inputs \
  --recipes recipes.json --candidate-pins candidate-binaries.json \
  --tools /path/local-tools.json --out /path/new-full-replay
```

The direct protocol helper additionally reads saved full native reference indexes, positive tiny deltas, and expected snapshot hashes from ordinary protected qualification output. These can be regenerated by the published qualification CLI; no issuer key is read by this helper. Supply each profile's qualification directory containing `references/`, `samples/`, and `summary.json`:

```sh
python replay_retained.py --inputs /path/inputs --recipe-dir . \
  --original-qualification /path/original-qualification \
  --expanded-qualification /path/expanded-qualification \
  --tools /path/local-tools.json --full-summary /path/new-full-replay/summary.json \
  --out /path/new-retained-replay
```

Full metadata inside as-run files preserves original absolute paths. Input files/deltas and tool digests are checked before use, with tool digests rechecked afterward. A newly built tool with different bytes needs separately identified new evidence rather than rewriting historical pins. `summary.json` lists exact complete/delta hashes for later CI input parity comparison. This package alone does not attest the remote CI machine or measure CI economics.

`SHA256SUMS` checks every package file except itself. No private keys, executable binaries or complete exports are present.
