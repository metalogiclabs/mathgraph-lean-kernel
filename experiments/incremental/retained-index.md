## Validity boundary

Cold initialization parses the genuine pinned baseline and compares its complete
typed index with the HMAC-authenticated, independently checked baseline receipt.
The Rust session retains declaration-key lookup, exact direct dependencies,
SCC membership, the condensation DAG and reverse edges, negative dependency
keys, closure roots and the original complete index. This state is private owned
memory, not an accepted serialized cache. Persisted baseline records and export
bytes retain the existing authentication and corruption checks on each update.

The public delta interface still admits only one baseline-anchored attempt. It
preserves declaration keys, names, kinds, order and count; complex declarations,
metadata and new declarations remain outside the producer's existing delta
policy. Unsupported inputs refuse rather than inventing an applicability proof.

For every replacement, the transition compares the complete normalized direct
dependency-key set, including unresolved negative keys. Exact edge preservation
implies the baseline SCC partition and condensation graph remain applicable.
Only SCCs with changed own identities and their reverse-reachable dependents
are rehashed, in dependency order. Each affected SCC hashes the same sorted
member `(key, own)` pairs, sorted outgoing closure roots and negative keys as
the qualified full implementation. All members receive the resulting closure;
affected builtin closure slots are refreshed as well.

Dependency changes, builtin inventory changes, builtin-body changes and axiom
assumption changes use the unchanged full `finish()` implementation. Its source
body remains the qualified reference. Metadata/kind/complex/new-declaration
mutations that the existing delta policy cannot admit remain refused/UNKNOWN;
they require an ordinary complete export and full verification. No uncertain
edge is treated as unchanged.

The producer attestation is checked before index mutation. Authentication never
grants kernel acceptance. Every successful update still materializes and hashes
the full sealed input and invokes the genuine selected checker, even for an
empty selected set. The original reuse predicate decides actual obligations.
Only successful checking issues accepted evidence.

## Independent comparison

`index-session CONFIG --full-finish` forces the old algorithm. The default uses
the retained transition, with explicit mode/reason and work counters. The full
returned index remains unchanged in schema, including every fingerprint and
dependency witness. Python's `DeltaSession(..., identity_mode='full')` selects
the control; the selected identity policy is bound into producer provenance.

`qualify_retained_index.py` compares current retained, current forced-full and
separately compiled/preserved qualified-449 adapters on the same existing early
and unrelated edits, in five paired repetitions. It also compares same-delta
native finishes independently of production, selected checking and persistence.
Fresh complete native and frozen qualified indexes, complete receipt audits,
actual selected counts and direct full Rust checks are required for every arm.
The inherited qualification retains all original correctness suites, positive
and negative cases, cold restart and C++/paranoid oracles.

`replay_retained_index.py` independently exercises edge additions/removals, new
and broken cycles, unresolved-key substitutions, mutations within mixed SCCs,
builtin dependencies and sparse name-table holes, restored dependencies,
failure poisoning and attempts to supply unchecked retained state. Its graph
fixtures test identity witnesses, not proof acceptance. Malformed unused rows
also reach the actual zero-selected parser and reject.

Both real profiles have the same affected closure cones: three declarations for
the early edit and one for the unrelated edit. Their actual selected-check sets
are larger because the existing conservative complex-declaration boundary is
unchanged. The leaf edit changes a dependency and exercises full fallback.

Five paired write/read measurements and forged/corrupt/cold controls are separate
from the retained adapter's end-to-end economics. This experiment is not integrated
into the production receipt path, and a correct negative economic result is retained.
